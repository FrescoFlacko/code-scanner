Positive fixture contract

The integration suite proves detection of:

  • A service client constructed inside handler
  • An async handler that also declares a callback
  • Logging the complete event object
  • An outbound URL derived directly from the event
  • process.exit() inside a handler

  • An unused TypeScript variable

Limits

  • Idempotency is business- and event-source-specific; linting cannot prove it.
  • Partial batch response, retry policy, timeout, memory, reserved concurrency, and IAM resource scope require infrastructure/deployment analysis.
  • Logging and event-derived URL findings are review hotspots, not confirmed vulnerabilities.
  • API Gateway authorization, backend access control, dependency vulnerabilities, and runtime data flow require separate controls.

Recommended gate: fail CI for parser errors and reviewed definite security/reliability findings. Keep handler-architecture, logging, SSRF hotspots, complexity, and cleanliness advisory until a real Lambda repository is scanned and triaged.
